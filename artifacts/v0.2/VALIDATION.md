# v0.2 验证记录

日期：2026-09-10。环境：Apple Silicon / macOS 26.5.1 / Swift 6.3.2。

- 原生 arm64 应用编译成功，本地代码签名校验通过，版本 0.2.0。
- 40 项模型检查通过：原有分笔逻辑、世界坐标、缩放锚点、双向映射、视窗平移、缩放边界、双指同时平移和缩放、接触身份变化、压力到粗细映射、关闭压感、原地加压、毛笔速度变化、导航起始误触点处理、旧版草稿兼容、新版草稿序列化、作品边界。
- 17 项应用内检查全部通过，见 `smoke-results.json`。接触路由与真实 NSTouch 输入共用相同代码，验证双指手势不留墨、剩余一指不落笔、全部抬手后的正确落点，以及光标控制、笔刷轮廓与整幅 PNG 导出。
- 已查看整体截图 `window-smoke.png`、250% 放大截图 `window-detail.png` 及导出 `export-smoke.png`。普通笔等宽且连续；压感示例由细到粗；毛笔有宽度过渡及起收笔尖锋。
- 视觉检查曾发现笔画轮廓填充方向不一致产生空洞，现已修复，并新增普通笔中心线与毛笔中心线连续性检查，最终结果通过。
- 新版安装在 `~/Applications/触控板手写 2.app`。独立应用标识避免与运行中的旧版混淆；新版草稿写入 `draft-v2.json`，首次可读取 `draft.json`，不覆盖旧文件。

自动测试使用合成接触与压力数值，不读取或修改用户草稿。真实双指操作、Force Touch 事件是否由硬件发出、压感手感、延迟与长时间大幅作品性能仍需本机实际试用。测试通过不等于已验证真实手指压力输入。
